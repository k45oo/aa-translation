## 流水线

脚本：`scripts/tools/gen_konosin_wiki.py`（用 `.venv/Scripts/python.exe` 跑，四段可独立重跑、幂等）

```bash
cd <repo>
.venv/Scripts/python.exe scripts/tools/gen_konosin_wiki.py --fetch      # 抓原站 710 页（走 v2rayN 代理）
.venv/Scripts/python.exe scripts/tools/gen_konosin_wiki.py --extract    # 抽正文/表格/AA 画，切行
.venv/Scripts/python.exe scripts/tools/gen_konosin_wiki.py --translate  # 批量汉化（只发文本行，AA 画行不发）
.venv/Scripts/python.exe scripts/tools/gen_konosin_wiki.py --fix-kana   # 只补译「译文里残留假名」的行
.venv/Scripts/python.exe scripts/tools/gen_konosin_wiki.py --build      # 出 index.html + 两个 json（零 API）
```

**实际成本：583 次调用 / ¥0.83**（`mimo-v2.6-flash`，prompt 64.9 万 tok，缓存命中 37%，输出 21.2 万 tok；见 `usage_stats.py --cost` 的 `tag=konosinwiki`）。

## 译名口径（优先级从高到低）

1. `人工修正.json` 的 `本地译名` —— 本作专名人工表（**最高**，压过一切通用表）
2. 本作术语表 `aaManga/この素晴らしいシンオウに祝福を/work/glossary_この素晴らしいシンオウに祝福を.json`（人工确认过）
3. 作品知识库 `work/この素晴らしいシンオウに祝福を_knowledge.json`（人物/术语）
4. 宝可梦 wiki `doc/aa作品相关/ポケモンAA术语wiki/补充术语.json`（通用补充）
5. 宝可梦官方译名对照（52poke）

### 名称的两个坑（已处理）

* 本作大量个体是**借名**（怪物猎人 / 数码兽 / 卡比 / 机战…)的『固有種』，模型「只翻页名、无上下文」时会蹭发音相近的**别的宝可梦官方名**（`フレイザード→暴雪王`、`ジンオウガ→雷吉奇卡斯`、`メタナイト→巨金怪`）。已按外作通行中文名逐条纠正（`KNOWN_OFFICIAL` 表 + `人工修正.json` 的 `按源替换`）。
* 页内【名前】行与页面标题由**两次独立调用**产生，会写出两个名字。构建时统一以标题口径为准（`--build` 自动对齐），并把仍有分歧的 189 条写进 `待确认名称.md`。

**改名字的办法**：在 `人工修正.json` 的 `本地译名` 加一条 `["日文名", "中文名"]`，重跑 `--build`（离线、零 API），页面标题与页内【名前】行会一起改过来。
**优先级**：`本地译名`（本作人工表，最高，可覆盖脚本内的 `KNOWN_OFFICIAL` 常量）> `KNOWN_OFFICIAL`（脚本里已认得的外作官方名）> 模型缓存译文。
**2026-10-03 联网核定**：189 条分歧逐条查中文维基／萌娘百科／各作官方译名，68 条定案写入 `本地译名`（例：`ネルスキュラ→影蜘蛛`、`アカムトルム→霸龙`、`エンジェウーモン→天女兽`、`ガウェイン→高文`、`ソリッド・スネーク→索利德·斯内克`、`シナンジュ→新安洲`、`聖園ミカ→圣园未花`、`ウオッカ→伏特加`），全过程见 `名称核对结果_联网.md`。

## 已接入宝可梦链的翻译前替换（2026-10-03）

本 wiki 现在是宝可梦专属链**术语强制替换**（`scripts/common/pre_terms.py`）的词源之一——
翻译某章前，本 wiki 的条目会连同通用 AA wiki、作品术语表一起按**本章语料**过滤，
命中的词在**送模型的那份文本**上先替换成标准译名（原文/宽度/art 列位口径不变）：

| 来源 | 取什么 | 词源标签 | 优先级 |
| --- | --- | --- | --- |
| `人工修正.json` → `本地译名` | 人工裁定（含本页联网核定结果） | `本作wiki-人工` | 1 |
| `术语表.json` → `terms` / `pages` | 本作原创招式/特性/潜能 + 页面标题（「名前」口径） | `本作wiki` | 1 |
| 通用 `ポケモンAA术语wiki` | AA 术语 + 官方译名对照 | `wiki-术语` / `wiki-官方` | 0 |
| 作品术语表 `work/glossary_*.json` | 人工确认条目 | `作品表-*` | 2（最高） |

* 目录解析：env `AA_WORK_WIKI_DIR` > `work_meta[work]["wiki_dir"]` > 约定 `doc/aa作品相关/<作品>wiki`
* 单独开关：`AA_PRE_TERMS_WORK_WIKI=0`；整体开关：`AA_PRE_TERMS=0`
* 实测收益（4 章）：可用词新增 **140/699（≈20%）**，且与通用表不重复——补的正是**本作特有**的个体名与原创招式/潜能
* 改完词表**不必重跑翻译链的配置**：词表按文件指纹缓存，wiki 重建（`--build`）后自动失效


## 已知取舍

* AA 字符画**不翻译**（用户约定：艺术行绝不进模型），只做原样保留。
* 页面「分类」按正文结构判定（含【タイプ】/【名前】或首行「ポケモン図鑑」→ 宝可梦个体；首行「登場人物」→ 人物），原站本身只用「一般/総合」两个标签。
* 少量条目仍可能有误译（如 `ヤミ→暗`、个别借名音译写法）；`待确认名称.md` 是人工收口的入口。
* 本环境 vision 模型（`xiaomi/mimo-v2.6`）在 commandcode 端点不可用，渲染校验走的是 DOM/CSS 量测（分类计数、逐行对照 `.jl`、无横向溢出），未做截图人眼复核。
