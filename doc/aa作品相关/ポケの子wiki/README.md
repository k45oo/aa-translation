## 流水线

脚本：`scripts/tools/gen_work_wiki.py`（**每部作品独立**，配置在 `scripts/config/work_wikis.json`）

```bash
cd <repo>
.venv/Scripts/python.exe scripts/tools/gen_work_wiki.py --work ポケの子 --crawl      # 抓页面一览 + 全部页（走 v2rayN 代理）
.venv/Scripts/python.exe scripts/tools/gen_work_wiki.py --work ポケの子 --extract    # 抽正文/表格/AA 画，切行
.venv/Scripts/python.exe scripts/tools/gen_work_wiki.py --work ポケの子 --translate  # 批量汉化（只发文本行，AA 画行不发）
.venv/Scripts/python.exe scripts/tools/gen_work_wiki.py --work ポケの子 --fix-kana   # 只补译「译文里残留假名」的行
.venv/Scripts/python.exe scripts/tools/gen_work_wiki.py --work ポケの子 --build      # 出 index.html + 两个 json（零 API）
.venv/Scripts/python.exe scripts/tools/gen_work_wiki.py --work ポケの子 --update     # 连载更新同步（见下）
```

* `--update` = **重抓全部页**（零模型成本，纯网络 1~2 分钟）→ 重新抽取 → 增量翻译（行级缓存，只译新行）→ 重建。
  抓取阶段逐字节比对缓存，报出「新增页 / 内容改动」，已删页自动剔除（`_raw/crawl_report.json`）。
* 作品连载更新后跑这一条即可；论文成本≈0（原站改一行只重译该行）。
* 想改一处译文：写进 `人工修正.json` 的 `修正`（整行覆盖）或 `按源替换`，重跑 `--build`（离线零 API）。
  要让**已缓存的行**吃到新译名：删掉那些行的缓存键（`_raw/lines_zh.json` 里键=日文原文）再跑 `--translate`。

## 译名口径（优先级从高到低）

1. `人工修正.json` 的 `本地译名` —— 本作人工表（**最高**，压过一切通用表）
2. 本作术语表 `aaManga/ポケの子/work/glossary_ポケの子.json`（人工确认过）
3. 作品知识库 `work/ポケの子_knowledge.json`（人物/术语）
4. 宝可梦 wiki `doc/aa作品相关/ポケモンAA术语wiki/补充术语.json`（通用补充 + 作品专属）
5. ポケマス AA 术语 + 52poke 官方译名对照

### 借名的坑（本作最要命的一类）

本作个体**全部是借名**——名字取自别的作品（怪物猎人 / 数码兽 / 高达 / 赛马娘 / 舰これ / 碧蓝档案 /
Fate / JoJo / 卡比 / 少年漫…），而**体内是宝可梦**。模型「只见页名、没有上下文」时会蹭成
**发音相近的别的宝可梦官方名**，例：`メタナイト→巨金怪`、`ガノトトス→盖诺赛克特`、`カメック→卡咪龟`、
`キングキタン→大岩蛇`、`イビルアイ→勾魂眼`、`デミウルゴス→三首恶龙`、`シルドラ→暴鲤龙`、`マドロック→岩殿居蟹`。

已处理：88 条本作人工译名（`人工修正.json` 的 `本地译名`）按**借名原作的通行中文名**逐条纠正
（`ジンオウガ→雷狼龙`、`リオレウス→火龙`、`エンジェウーモン→神圣天使兽`、`メタナイト→金属骑士`、
`アーモンドアイ→杏目`、`カービィ→卡比`、`空母ヲ級→航母WO级`、`マドロック→泥岩`、`トリシューラ→三叉龙`、
`オッドアイズ・レイジング・ドラゴン→异色眼狂怒龙`、`エメラトトス→翠水龙` …）。
改名办法：在 `人工修正.json` 的 `本地译名` 加一条 `["日文名","中文名"]`，重跑 `--build`（离线零 API）；
若该名字已散落在缓存译文里，删掉相应缓存行后跑 `--translate`。仍未定案的见 `待确认名称.md`。

**注意（给翻译链的提醒）**：`术语表.json` 的 `pages[].title` 会作为「本作wiki」词源注入翻译前替换，
所以**页名译错 = 译文被强制改错**。发现新错名务必先改这里再翻新章。

## 已接入宝可梦专属链的翻译前替换

本 wiki 是宝可梦专属链**术语强制替换**（`scripts/common/pre_terms.py`）的词源之一——翻译某章前，
本 wiki 的条目会连同通用 AA wiki、作品术语表一起按**本章语料**过滤，命中的词在**送模型的那份文本**上先替换成标准译名
（原文/宽度/art 列位口径不变）：

| 来源 | 取什么 | 词源标签 | 优先级 |
| --- | --- | --- | --- |
| `人工修正.json` → `本地译名` | 人工裁定（44 条） | `本作wiki-人工` | 1 |
| `术语表.json` → `terms` / `pages` | 本作原创招式/特性/潜能 + 页面标题（「名前」口径） | `本作wiki` | 1 |
| 通用 `ポケモンAA术语wiki` | AA 术语 + 官方译名对照 | `wiki-术语` / `wiki-官方` | 0 |
| 作品术语表 `work/glossary_ポケの子.json` | 人工确认条目 | `作品表-*` | 2（最高） |

* 目录解析：env `AA_WORK_WIKI_DIR` > `work_meta[work]["wiki_dir"]` > 约定 `doc/aa作品相关/<作品>wiki`（本作命中约定，无需配置）
* 开关：`AA_PRE_TERMS_WORK_WIKI=0` 单关本作 wiki；`AA_PRE_TERMS=0` 全关
* 本作 wiki 词源实测 **957 条**（人工 44 + 自动 913）；抽查第 1 話：术语命中 75 行 / 85 次
* 验收报告（零 API）：`python scripts/tools/gen_pre_terms_report.py --work ポケの子 --base entry_31726`

## 已知取舍

* AA 字符画**不翻译**（用户约定：艺术行绝不进模型），只做原样保留。
* 五十音图索引小节标题（`あ`/`か`/…）保持假名，已写进 `人工修正.json` 的 `修正` 段（模型会误译成「啊/是/啦/哇」）。
* 少量借名仍未定案（见 `待确认名称.md`，42 条），页面标题与页内【名前】行写法不一致的也在其中。
* **`修正` 会被繁→简归一覆盖**：`--build` 最后统一跑 zhconv(`zh-cn`)，`蟇郡苛` 这类会被归一成简中写法 `蟆郡苛`
  （这是**对的**——简中写法如此），故想钉住传统字形时不能用 `修正`，得改生成器的归一例外。
* 本环境未做截图人眼复核；渲染校验走 DOM/分类计数/逐行对照结构。
