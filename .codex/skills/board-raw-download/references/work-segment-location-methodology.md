> 旧说法：雑談所贴内「不直接写第N話标题」「按 第N話 标题扫描定位」——实测两个都错。

## 核心教训

### 1. 作者「会写」稀疏的第N話，但它是陷阱
- 作者会写：10スレ目 res693第0話/698第1話/710第2話/870第9話、5スレ目 res3140第2話/3254第3話/3466第5話、6スレ目 res1324第1話、9スレ目 res3653第1話/3736第2話/4033第3話/4350第4話。只是不连续（第1話/第4話等会漏标）。
- **别只靠「第N話」**：同一スレ连载多部作品，这些标记大多属于**别的作品**——
  - 10スレ目 res693/698/710/870 的「第0/1/2/9話」是《お父さんとエッチしているけど異世界だからいいよね！》(上下文「お父さんとエッチしているけど異世界だからいいよね！　第N話」)
  - 9スレ目 res3653/3736/4033/4350 的「第1-4話」是《ガンダム》(上下文「作者がガンダムをやる夫スレとwikiでしか知らない」)
  - 扫「第N話」直接定位会抓到别的作品 → 必须先辨作品。

### 2. 共享角色不可靠，靠舞台词
- 女配角「水銀橙」、主人公「紲星あかり(あかりちゃん)」在《村》《街》两作都登场 → 扫角色名会把两作+讨论楼混一起。
- 可靠判别 = **舞台场景词**：
  - 《紲星あかりは狂った村に囚われるようです》(「村」)：`村 / 集落 / 廃村 / 村の長 / 村娘 / 村人 / 山道 / お父さん`
  - 《紲星あかりは歪んだ街に迷い込むようです》(「街」外传)：`歪んだ街 / 街の住人 / この街 / 街娘`

### 3. 只扫作者楼，滤掉名無し讨论
- 名無し也大量提角色名（あかり/お父さん），但那是讨论非正文。只扫发帖名含 `コンプレックス` / `◆` 且命舞台词的楼。

## 有效步骤
1. 对每个 dat，抽作者楼（名含 コンプレックス/◆）+ 命舞台词的楼号。
2. 聚类成段：相邻楼号间隔 >~40-50 楼 → 开新段（作者中途插名無し/换作品/去睡觉，间隔大必是新段）。
3. 抽查每段首尾楼台词（非纯 AA 行）确认是本作正文——关键词会误包裹别的作品簇：
   - 9スレ目 res718-1025「水銀橙」簇实为《横島くん》(res718「ハッピーバースデーイブ、忠夫」、res1020「横島くん」)
   - 5スレ目 res2978「運転免許取ったからって１８歳の小娘が一人でドライブなんてするんじゃなかった」确认是「村」开篇
4. 章节起止 = 作者开始/收尾信号：`開始します / 中断します / 再開します / お付き合いありがとうございました / それではまた夜に / 次回は / 仕事行ってきます`。
5. 话数核对：用已下载镜像站版 `aaManga/<作品>/aa/entry_<eid>.txt`（标题带「第N話」）各话开场台词交叉确认。
