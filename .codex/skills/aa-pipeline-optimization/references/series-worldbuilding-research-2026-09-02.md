# AA 系列共享设定调研（新作用术语不讲解时）+ ポケモン AA 设定速查（2026-09-02）

## 触发场景

某 AA 系列作品共享一套自创设定（如ポケモン AA 的 ポテンシャル/四大資質/四式六令），**新作默认读者懂、直接扔术语不解释**——本地 3 部宝可梦作（シンオウ 810章/ポケの子 416章/生き直す 167章）均无汉化，翻译/理解前需先建立设定框架。

## 调研流程（验证过，5 步）

1. **站端标题搜术语几乎必空**（术语不出现在标题，如 `aa_search.py 四式 --site r401` 返回 0 条）→ 直接 `web_search` 日站：术语 + 作品特征词（`ポケモン やる夫 四式 六令` 比裸术语命中率高得多）。
2. 从结果定位 **①系统源头作品及其专有 wiki**（ポケマス→ seesaawiki.jp/pokemasu2）+ **②同好帖**：ハーメルン捜索掲示板（syosetu.org `?mode=seek_view&thread_id=<N>`）有人问「採用〇〇システム的作品清单」→ 帖子回复即作品名录（岛流されアカリ/ポケモンユカリ/Yell/ポケの子/シンオウ 均四式六令系）。
3. **本地库扫正文定体系归属**：`.venv/Scripts/python.exe` heredoc 遍历 `aaManga/<作>/aa/entry_*.txt`，每作每术语统计命中文件数/处数（用 `txt.count`，别 grep 子进程）——判断哪些作同体系、用量级、并找**讲解回**（旧作正文常有完整【System】讲解段；ポケの子 entry_31758 第33话整回定义四大資質+主角面板 指示A/育成B/統率B-/能力C）。
4. 抓 wiki 权威定义 → 产出速查文档到 `doc/aa作品相关/`（例：`ポケモンAA四大資質四式六令设定速查_2026-09-02.md`，含传承链/完整定义/初译术语建议/参考链接）。
5. **术语译名只给「建议」，待人工确认**（AA 工作台惯例：未确认译名用原文，勿猜）。

## seesaawiki 抓取坑（本会话实测，5 条）

- **代理出口 IP 403，直连 200**——`curl -x http://127.0.0.1:10808` 拿到 403 Forbidden，去掉 `-x` 直连 200/45KB。seesaawiki 不拦非代理出口。
- **页面 EUC-JP 编码**——按 UTF-8 读全乱码（`�` 泛滥）。用 `raw.decode('euc-jp', errors='replace')`（cp932 也失败，0xad 非法）。
- **真正文嵌在渲染页 ~10000 字符偏移后**——开头是 jQuery 脚本/侧栏/站公告/广告。`cmd=source&page=` 源码接口返回的**仍是同一渲染页**（45KB，非 wiki 源码）。meta description 只含站公告不含正文。
- **tvly extract / web_extract 只能取到侧栏菜单**（正文区是渲染的，抓取器拿到的是菜单链接列表）——正文必须 curl 直连自己解。
- **可靠提取法**：curl 直连（无 -x）→ `decode('euc-jp')` → 从关键词位置（如「四式六令」）`txt.find` 截取正文区 → 去 `<br>`/`</p>` 标签转行 → 去 `<[^>]+>` → `html.unescape`。grep 关键词位置：`re.finditer(re.escape(kw), txt)` 看出现 idx，正文区在第二次出现后（第一次常在 JS/菜单）。

## ポケモン AA 设定体系速查（译名建议初稿）

完整版含传承链表格/各資質逐ランク效果/ポテンシャル体系术语表 → `doc/aa作品相关/ポケモンAA四大資質四式六令设定速查_2026-09-02.md`。要点：

- **四大資質** = 训练师 4 面板：指示（導き戦況を組み立てる）/ 育成（育て強さの道を示す）/ 統率（率い軍勢として従え操る）/ 能力（个人异能）。ランク E<D<C<B<A<AA<AAA<S<EX，A=優れた長所/B=高水準/C=人並み。**版本表记差异：ポケマス系用「指示」，アカデミア系用「指揮」**。
- **四式** = 『かわせ！』（避物攻）『よけろ！』（避特攻）『もどれ！』（后手换人）『たえろ！』（硬撑半减）+ AA 级『あたれ！』（必中）。**六令** = 攻撃/防御/特攻/特防/敏捷/回復 六指令（1T 强化）。発展形：熟達系（指示C）→ 全開系（B）→ 狙撃/回避（A）→ AA 混成。
- **ポテンシャル** = 技能总称：固有（训练师异能，資質联动：指示→四式/指令、育成→技能拡張、統率→役割/フィールド、能力→異能）/ 専用（单只专属）/ 種族（种族阶）/ 役割（統率任命：ブロッカー/スイーパー/エース/キラー/アシスト）/ エキスパンション（属性扩张）/ 絆 / ヌシ（霸主，深度 1-4）。
