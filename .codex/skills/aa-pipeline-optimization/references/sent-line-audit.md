# 送模型行集合审计（艺术行混入率）——改分类器前先量这组数

改任何「哪些行进模型」的规则（`is_text_line` / `line_meta_v2` / 新增否决）之前先跑审计，否则改完没有基线可比。

## 跑法

```
.venv/Scripts/python.exe <skill>/scripts/audit_sent_lines.py            # 全库，每作品前 6 章
.venv/Scripts/python.exe <skill>/scripts/audit_sent_lines.py --ckpt     # 加跑 ckpt 回声核对
```

口径（**必须复用生产同一条判定链，勿另写分类器**）：

- 送模型行 = `aa_translate.is_translatable(idx, line, meta)` 为真；
  `meta = load_meta_0based(work_dir/line_meta_v2, base)`（1-based→0-based），meta 缺失或 idx 不在映射 → 回退 `is_text_line`。
- 「艺术行」= 无平假名（U+3041-309F）**且**无 `ART_KANJI` 之外的汉字。**这是上界**：纯片假名台词（`ナニソレ`/`ヤダ`）也会被算进去，能直接当否决条件用。

## 基线（2026-10-08 实测，104 部 ×6 章，41.6 万行 / 2308 万字符）

| 口径 | 值 |
|---|---|
| 送模型行 / 字符 | 415,604 行 / 23,083,375 字符 |
| 其中艺术行 | **149,585 行 = 36.0%，字符占 38.5%** |
| 无 `line_meta_v2` 目录的作品 | 8 部（整章走 `is_text_line` 回退，如 白头与染灰魔女、时间停止探索者亚鲁欧） |
| 有 meta 也被标 `text`/`mixed` 的艺术行 | 65~67%（VOICEROIDが売り物の世界、やる夫広場短編集）；文本密集作品降到 13.3%（この素晴らしいシンオウ）/ 9.0%（ポケの子） |

对照成本：`usage_stats.py --cost --days 60` 的 translate 一栏 83,104 次调用 / 1.951 亿 prompt token / ¥155.66（缓存命中 64.3%，故金额影响小于 token 影响）。

## 证据链：光看行集合不够，要看 ckpt

ckpt 里 `译文 == 原文` = 该行进过请求、模型原样复述。实测某章 2933 条 ckpt 里，1972 条属艺术行、其中 **1950 条译文 == 原文**。这条链比“行集合比例”硬——行集合只能说明“会被送”，ckpt 能说明“确实送了且白烧”。`--ckpt` 就是跑这个。

## 判定与改法

- 连续 ≥2 平假名才是强锚点（AA 几乎凑不出连续真平假名）；`ノミニハマレヘ` 这类全角片假名艺术字**能从假名区凑出来** →「有假名」不等于「是台词」，别再只靠 `has_kana`/`KANA_RE` 判可译。
- 顺序：先硬否决 → 再打分 → 最后才是跨行脉絡。硬否决：同字 ≥3 run `([ニ二三ミ彡爻从乂工ﾆﾐ])\1\1`、眼睛笔画「Xうぅ」（前接汉字/片假名/横线）、手 `[と⊂][^ぁ-ゖ一-鿿々]+[つ⊃]`。笑声 `ハハハ`、拉长音 `あああ` 用别的字，不撞同字 run 规则。
- **别直接把「无平假名 + 无实义汉字」当否决条件上线**：纯片假名台词会被误杀。需行尾对话区、句末标点、短词豁免兜住，并先做 A/B（对比送模型行集合 + 抽查被否决行是否含真台词）。
- 修分类器时**两条路径都要管**：meta 缺失的回退路径（`is_text_line`）与 meta 自身把全角片假名艺术行标成 `text`/`mixed` 的那一类——只修一边，混入率不会降。

外部同类实现的做法（候选级提取 + 打分 + 硬否决 + 文档级名牌救援）见 `references/external-aa-tools.md`。
