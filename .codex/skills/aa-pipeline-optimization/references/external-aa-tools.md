# 外部 AA 汉化实现对照：可抄 / 不可抄

读别人的 AA 汉化实现时按这份清单核对，别整段照搬——形态不同（他们多为**人在环逐话手动**：提取→粘给 AI→回填→编辑器微调；本项目是全自动批处理）。

## AATool（zseineo/infrared-singularity，PyQt6 桌面工具，单 exe）

形态：2ch AA 页 → 提取候选台词 → 用户粘给 AI（API 或 Playwright 驱动网页版 Gemini）→ 回填 → 富文本 AA 编辑器手动微调。技术规格书 370KB，逐函数写明改法与实测数字（很值得读的文档习惯）。

### 可抄

1. **候选级提取 + 打分**（他们整条管线的地基，本项目是行级）：锚点 = 连续 ≥2 平假名 / 连续 ≥3 片假名 / 汉字+助词 / 送假名（汉-平-汉）/ 短句+句末标点 / 数字选项 `①～⑳：` / 成对术语括号（`【】《》〔〕『』〚〛`）；边界贪心扩展；再打分 `_SCORE_THRESHOLD = 2`（+3 平/片假名 run、+2 助词、+2 送假名、+3 数字选项、-3 同字片假名 run ≥3、-4 局部 AA 密度 >0.6（有强信号只 -1）、-5 自身噪声 >0.4、-2 类别跳转率 ≥0.5）。跨行脉絡：整份文本先分类 text/struct/aa/neutral，`text` 候选 +2、AA 块且无平假名 -2。
2. **硬否决**（放在 min_len 之后、打分之前，**不进落选收集、不可被名牌救援救回**）：
   - AA 墙 `([ニ二三ミ彡爻从乂工ﾆﾐ])\1\1`（同字 ≥3）——依据：47 篇实测命中处 28 笔全为 AA 碎片；笑声 `ハハハ`、拉长音 `あああ` 用别的字不撞。
   - 眼睛笔画：`Xうぅ`（前接汉字/片假名/⌒/横线）或 `うぅX`（后接 ミ/彡/x）——57 篇实测 46 处全为 AA。
   - 手 `[と⊂][^ぁ-ゖ一-鿿々]+[つ⊃]`（`とエェェエエつ` 型）。
3. **右侧 AA 补位/消位**（`pad_right_aa`）：译文比原文短 → 按显示宽度补全形空白，把右侧 AA 推回原列；译文更长 → **吃掉右侧空白**（不动 AA 字符本身）保持右 AA 列位。排除：右尾是纯横线分隔线、或整段是假名（拟声词）时不补。本项目 `allow_overwidth` 只解决了超宽方向。
4. **术语替换打在 AA 图上的三条守卫**（`glossary_avoid_aa`，本项目只有邻接守卫 + 歧义段）：规则 A 命中处 ±8 字窗内 AA 噪声密度 ≥0.5 则不换；规则 B 紧邻同类假名（硬切碎片）已有；规则 C 紧邻 ≥3 个**相同**装饰标点则不换。配套两条例外值得抄：两侧同类假名 run 被**本轮命中完整覆盖**就不算碎片（防 `エリクサー` 半替换成 `繪里クサー`）；左邻属格 `の` 且 `の` 前非平假名时不算碎片（`【アリスのはなふぶき】`）。
5. **送审前遮词**：把过滤词表里的词按「长的优先」换成**等长 `○`** 再送模型（只改 `ID|` 右侧、ID 不动），降低整段被审核挡下的概率；配合「回覆被換成拒絕語」判据（含罐头拒绝语、或原文 ≥N 行而回覆 ≤M 行）决定重试/补翻。本项目撞 content_filter 只会换端点重试。
6. **译文 ID 纠错**（`repair_translation_ids`）：AI 把 `564-1` 写成 `564-4` 时，四条件同时成立才改写（错 ID 不在原文但行号在、原文该行号只有一个 ID、译文里没有正确 ID、前后最近正确 ID 的行号包住本行）。本项目这类行直接落漏译清理。
7. **对话框边框自动对齐**（913 行，4 型：普通/吶喊/斜线/方框；字宽走 FontMeasurer 协议）：编辑器级功能，本项目人工矫正完全没有自动化。
8. **内嵌 AA 字体**：Monapo +3.5MB / Saitamaar +2.7MB / textar +4.3MB 以 base64 `@font-face` 塞进单档 HTML → 离线手机可读。注意 `file://` 下 web font 受 CORS 限制，外部字体文件不可靠，只能 data URI；授权风险见 `aa-delivery` 的 `references/font-and-width.md`。
9. **按投稿日期排章节**（`reading_order`）：用首个帖头日期（`2011/04/21(木) 00:35:17 ID:`）给文件名加 `NNN_` 前缀——番外/幕間没有话数时也能排在作者发表的位置。本项目章序来自原站分类页，原站顺序缺失时可用这招。

### 印证本项目已有（同类结论，可互相校对）

- 「kind=text 但整行无日语」的行占**发模型字符 21.3%** → 对应本项目 `AA_SKIP_NON_JP`（本地照抄）。
- 全局术语替换误伤 AA 图碎片（`::::アム::::` 里的 `アム`）→ 对应 `pre_terms` 邻接守卫。
- 假名折叠**只做单向平→片**：双向会让平假名 key 咬到 `はんきょう`（反響）尾巴产出 `はん阿桔`；平假名是助词/送假名的组成字元，没有可靠词界 → 与本项目 2026-09-30 的结论一致。
- 替换前按**最长原文优先**排序防嵌套替换。
- ID 跳号 = AI 把上下文相连的两段译成一句只回一个 ID → 本项目表现为漏译，靠 refine_aa 清理。

### 不可抄

- Playwright 驱动网页版 Gemini（拟人点击、防自动化检测、配额冷却）：成本/风控/复杂度都不划算，本项目用 API 链。
- PyQt 单 exe 打包 + Windows DPAPI 加密密钥：形态不同（本项目是本地 web 工作台 + 交付夹编辑服务）。
- 把术语/wiki **注入 prompt** 当主方案：本项目 2026-09-22 已实测无效，改为翻译前强制替换。
