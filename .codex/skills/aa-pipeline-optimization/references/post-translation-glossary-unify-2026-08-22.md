# 对已译章节做后置术语/角色名统一（宽度保持替换）

来源：2026-08-22 `トレセン学園人狼部`(jinrou, 43话已译) 用户拍板反转——原方针「狼人杀术语保留日文」改为**马娘角色名 + 狼人杀术语统一译中文（英文角色名除外）**，对已译章节做后置替换而不重译。这也是任何「已交付后发现角色名/术语没进术语表」场景的通用工作流。

## 核心工具

`aa_web_app/logic.apply_glossary_chapter(aa_path, tr_path, pairs, dry_run=True, backup_root=None)`
- 逐行对每章做**多对子串替换**，按 SRC 行宽自动 `pad_to_width`，跳过 `#`/`=====` 行，超宽行落 skipped 待人工。
- **`dry_run=False` 必须传 `backup_root`**（否则 `backup_files(paths, None)` 崩 TypeError）——给 `<work_dir>/backup_glossary/`（os.makedirs 先建）。
- **幂等**：可对同一章反复跑，只补上次漏掉的行（首次全量常留部分行，第二遍补齐）。
- 返回 `(changed, skipped)`；宽度复核用 `aa_common.disp_width` 逐行比对 `#`/`=====` 除外 == 0。

## 替换对组合（本例 114 对）

- **马娘全名 60+**：特别周/无声铃鹿/东海帝王/摩耶重炮/爱丽速子/黄金船/青云天空/荒漠英雄/北部玄驹/大和赤骥/玉藻十字/米浴/神鹰/小栗帽/爱丽数码/伏特加/目白麦昆/目白赖安/菱钻奇宝/超越/葛城王牌/高尚骏逸/美妙姿势/曼城茶座/美浦波旁/春乌拉拉/杏目/贵妇人/新宇宙/爱慕织姬/吉兆/真机伶/草上飞/里见光钻…
- **爱称 30+**（正文大量用简写，必加）：マックイーン→麦昆、オグリ→小栗帽、ゴルシ→黄金船、**スペ→小特**、マヤノ→摩耶、タキオン→速子、テイオー→帝王、カフェ→茶座、キタ→玄驹、**キング→采珠**、サト(→里见)…
- **狼人杀术语 ~24**：占い師→预言家、霊能→灵能、狩人→猎人、人狼→狼人、村人→村民、狂信者→狂信徒、背德者、共有者、初日→首日、強襲→强袭…

## 用户定稿口径（本作）
- **狐 不变**（不单独替换狐→狐狸）；`妖狐`→妖狐 保留。
- **吊り/吊る→吊**（人狼杀「吊」= 投票放逐）。
- 其他术语照译；`ブラック`→黑、白確定→确定白、占い→占卜。

## ⚠️ 核心坑（省大量人工的关键）

### 1. 爱称译成中文「变长」→ 大面积 skip 落 manual
短形昵称逐个算 `disp_width(日文) - disp_width(中文)`：本例 30 个爱称里**只有 `スペ→特别周` 变长(+2)**，其余全等宽或变短。
- `スペ`(4格) → `特别周`(6格)，让 12 行超宽被 skip。
- 改 **`スペ→小特`（4=4 等宽）** 后 0 skip。
- **教训：选爱称中文译文时优先等宽/变短的词**，能零人工跑完；变长的会系统性落 manual。

### 2. 替换对排序：先全名后爱称（长/特异优先）
爱称若排在前面会把全名子串吃掉（如 `オグリ`→`小栗帽` 若在 `オグリキャップ` 前，全名变样）。按「leng 特异组合 > 全名 > 爱称」排序。
- 叠字防护：`人狼人狼ゲーム`→`狼人狼人游戏`、`人狼人游戏`→`狼人游戏` **排在** `人狼`→`狼人` **之前**，否则出「狼人人游戏」。

### 3. 首次全量 run 会残留部分全名未替换
本例 `サトノダイヤモンド` 残留 26 行、`キング` 若干行未替换（替换对在部分行因组合/宽度原因未生效）。**再次对同章 dry_run=False 跑一遍即补齐**（幂等 + 补漏），不是 bug。收口顺序：跑→复验窗口→跑第二遍→复验 0。

### 4. 超术语表范围的整句漏译
术语表只能统一「词」，译不了**整句**。原机翻的句子级残留（`「曼城茶座」さんは村民協議の結果、処刑されました`、`人外陣営が人外に占卜で白を出すこと`）需另跑 pass3 补译（走 deepinfra 等可用后端），不能靠替换对。

### 5. 次要爱称可保留
`ターボ`/`フラッシュ`/`サトノ`/`パンダ`（非马娘吉祥物）等次要爱称/非角色词可在正文保留，读者可推断，不进替换对免得误伤。
