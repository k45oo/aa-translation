# aa_search.py 数据面探明 + 实现坑（2026-09-01）

`scripts/tools/aa_search.py`（v1 纯 CLI，4 源并行）实现时逐端探明的事实，新增/扩展搜索功能先读本文件。

## CLI 形态

```
python scripts/tools/aa_search.py <关键词> [--author 名] [--tag 标签] [--site r401|com|jp|net] [--r18] [--sort date|pop] [--json out.json]
python scripts/tools/aa_search.py ranking --site com|jp|net --period week|month|all
python scripts/tools/aa_search.py aliases [--promote]
```
- 缓存：`data/search/`（gitignore）r401 tags 映射 + 榜单，1 天 TTL；搜索结果不缓存实时
- 作者马甲 `scripts/config/search_authors.json`、重复折叠 `scripts/config/search_duplicates.json`：人工资产 git 跟踪，candidates 自动收集→人工设 `确认:true`→`--promote` 转正（glossary_candidates 同款流）
- `--web`（tavily）**已砍**：探针实测公开 web 只返回角色 wiki 词条（スライム=DQ 角色页等），无结构化作品数据

## r401 数据面（2026-08-31 实测）

- **archives?s= 题级搜索**（`/yaruo/archives?s=<kw>`）：item = 作品(cat 链接文本=作品名) + 章节(exlink href) + 站点(item-site) + 日期，40/页 `page=N` 分页（`href="...page=N"`）。EXLINK_RE 关键结构：
  ```
  data-rid-catid-param="<cid>"><a href="/yaruo/categories/<cid>">作品名</a>
  data-rid-arcid-param="<arcid>"><a class="exlink" href="...">章节名</a>
  item-site><a href="/yaruo/sites/<sid>">站点名</a>
  item-date>日期
  ```
- **categories?s= 作品名搜索**：只出作品头（`data-rid-catid-param` + 作品名链接），无 site/章节。**注意 `?s=` 是「最近更新流」非精确匹配**——泛词返回无关最新分类
- **authors?s= 是全作者表子串模糊流**：搜「ポン」返回ショボン玉/バカポン/ボンクラ 等。**必须精确过滤**：trip 词（含 ◆）`name in aname`；正名 `aname.split("◆")[0].strip().replace("★","").rstrip("＠") == name`。**aid 可能 404**（搜索流里的脏数据，如 ポン＠◆uIesmhw5pA★ aid=11717 → fetch 404 要 except 吞掉）
- **作者页 = 该作者出现过的全部分类**（含转载/他人合集——ポン 有 37 页上千条，本人作品只占小部分）。抓前 3 页 + 过滤合集标题：`_is_collection_title` = 标题含他人 trip（`◆xx` 非本人 trip）+ 词表（氏の作品集/氏の短編/の雑談/投下所/黒歴史/の製薬/の隔離施設/の証券取引所/の調剤所/一発ネタ）。本人 trip 要从 aid 名提取 `own_trips` 集合。作者页分页 `?page=N`
- **tags**：`/yaruo/tags` 全量清单页 32 个一次抓全（`href="/yaruo/tags/(\d+)">名称`）；`/yaruo/tags/<tid>` = 分类级作品页（同 categories 结构，cid 集合），オリジナル=6、R-18表現含む=26
- **rank**：`/yaruo/rank` 单页四块 `<h3 id="access1|access2|access3|new">`，条目 `<li><a href="/yaruo/categories/<cid>">名字</a>`。access1=連載(111 条)/access2=作者名連載短編(66)/access3=作者(50)/new=新人(80)。**无独立累计块**——period all 复用 access1。日期无年份（`05月10日 01時00分`）→ 按当年推会出未来日期，可接受
- **日期**：分类/tag 页 `YYYY年M月D日`；archives `M月D日 HH時MM分`（无年）

## yaruobook 数据面

- **`?s=` 是 WordPress 站内全文搜索（正文命中）——2026-09-01 用户纠正**：命中章节标题**可能不含关键词**（实测搜「初音ミク」com 109 卡里 107 张标题不含、net 163 卡**全部**不含；搜「初音」能把「できる夫の相棒は全知全能なようです」154 章全命中）。不能当标题搜索用——用户原话「搜索的章节名可能不含关键词」
- **每张搜索卡片自带 cat-label = 所属作品分类（按作品聚合的正道）**：`<span class="cat-label cat-label-<cat_id>">作品名</span>`（含在卡片 `<a class="entry-card-wrap">` 的 `<article>` 里）。按 `cat_id` 聚合到作品，**不要剥标题猜作品名**——`やる夫のダンジョン運営記191-本編033　第17話「...」` 这类「作品名+章节号+话数」复合格式剥不干净（初版正则猜错作品名）。聚合键 `yb:{site}:{cat_id}`。偶见 cat-label 与章节标题作品名不一致（分类改名旧章未改，如「モルガンと往く人理修復」章节还叫「トネリコの往く人理漂白」）——以 cat-label 为准
- **分页是 `paged=N`**（WordPress 标准，`page=` 被忽略恒返第一页）——与 r401 的 `page=` 不同！300 条/页。net 站 ~40s 慢但可用；com/jp 偶超时（timeout=120 起）
- **searchandfilter = POST 表单**：`<form method="post" class="searchandfilter">` + `input[name=ofsearch]`（关键词）+ `select[name=ofcategory]`（作品分类 id 下拉，option value=cat id，如 401=咲-saki- ANKO やる夫編）。POST 提交才是 tag/分类过滤
- 三站域名：com=yaruobook.com / jp=yaruobook.jp / net=yaruobook.net

## 聚合/已收录标注

- 聚合键 = r401 cid 优先，yaruobook 用规范化标题（`norm_title`）；同 cid 多章节合并
- **本地已收录三重比对**：① `registry.WORKS[w].r401_cid` == 结果 cid；② `work/site_url.json` 的 url 归一后 == 结果 site_url（`?cat=N` → `yaruobook:cat:N`）；③ 规范化标题 ∈ registry title / work_meta jp_title / cn_name
- **norm_title 顺序坑（真 bug，调了很久）**：R18 前缀剥离（`【R-18】`/`【R18】`/`【18禁】`/`【R18G】`/`【１８禁】`+全角）必须在**括号删除之前**——先执行 `re.sub(r"[【】\[\]\(\)（）\-\s]","",s)` 会把 `【R-18】` 变 `R-18`，前缀正则匹配不到，`-` 又被删成 `R18` 残留。正确顺序：剥前缀 → 全角→半角（`\uFF01-\uFF5E`）→ 删括号/空格 → 剥系列后缀（のようです/第N話/番外）
- **站点归一 site_key**：r401 站名「やる夫スレ本棚/2号館/別館」↔ yaruobook com/jp/net 映射同键（防同站不同名误判跨站重复）
- 重复折叠：确认组（search_duplicates.json `{规范键: [标题列表]}`）→ 同 norm 标题非 local 记录折进主记录 mirrors 列表

## 坑汇总

- 子命令（ranking/aliases）必须在 argparse 前按 `sys.argv[1]` 分派——keyword 位置参数会吞 `ranking` 报 unrecognized
- `ThreadPoolExecutor` 闭包循环变量用 `(lambda n: lambda: fn(n))(nm)` IIFE 立即求值
- yaruobook 聚合记录带 `chapters` 列表（无 r401 的 chapter 字段）——聚合循环要接住两种形状，`chapter_count` 取 max
- `--author` 模式只跑作者线（aliases 展开马甲多路），**不混关键词搜索**（r401 ?s= 噪声大）
- 平台差异：r401 `page=` / yaruobook `paged=`；r401 搜索流非精确 / yaruobook ?s= 是精确章节级
