# 本地汉化 vs 人工参考 质量对照审核 + 宽度安全修正（2026-08-21, 時間停止探索者やる夫 1-10话）

> 会话实战：`aaManga/時間停止探索者やる夫/汉化/entry_{42170-42178,2012}_汉化.txt` 对照 AAFanClub `交付HTML/时间停止探索者亚鲁欧/时间停止探索者{001-010}话.html`（AAFanClub = 翻译同好会人工翻译, 用户指定"基本无错, 作权威参考"）。产出 `doc/时间停止探索者_本地翻译质量对照报告_1-10话.md`。

## 就绪工具（仓库内）
- **抽取对齐**：`scripts/tools/compare_translation.py` — 站点 html 与本地 txt 都按帖头 `NNN ：` 分帖(レス番号), 每帖抽台词(连续汉字 run), 生成 doc/…_本地vs人工_逐帖对照.txt（REF/LOC 并排, 纯艺术帖跳过）。
- **宽度安全修正**：`scripts/fix/fix_translation_review.py` + 修正表 JSON（`{文件:[{post:N,old,new}|{old,new,all}]}`）→ 替换 → strip 行尾垫宽 → 按原文 `disp_width` 重 pad → 超宽拒写 → 行数/colormap 不变、幂等。修正表存 `<work>/fixes_<tag>.json`。
- **对照底座**：`scripts/common/gen_aa_html.py --work <registry_id>` 重生成交付 html；作品 id 见 `scripts/works/registry.py`（本作 `jikan_teishi`）。

## 流程要点
1. **先确认章节映射**：本地文件 `# 标题` 行有「第N話」；AAFanClub 编号 = 话数。用 `# 原帖地址`(yaruobook.com/?p=XXXX) 与本地 entry_XXXX 对不一定要一致，直接按「第N话↔NNN话.html」配对即可。
2. **话切分可能不同**（AAFanClub 001=帖2471-2551 vs 本地第1話=2473-2571）——只对齐公共帖 (`set(ref_posts) & set(loc_posts)`)，边界帖列「仅站点有/仅本地有」但不评质量。
3. 5 个子代理按话并行深读 REF/LOC 并排文件, 产出「帖号|类型|LOC|REF|说明」；类型=错译(意思反转)/漏译/表达生硬/用词不当/术语人名不一致/宽度截断。
4. **每条疑点落地前必须回验实际 `_汉化.txt` 行**（子代理与 run 抽取都会被头号坑带偏）。

## ⚠️ 头号坑：汉字 run 抽取的假阳性（本会话几乎改错文件）
`re.findall(r'[\u4e00-\u9fff]+')` 只取连续汉字 → **丢掉假名(やる)/拉丁(JOJO)/阿拉伯数字(3,2,1)**，同时行内 U+3000/空格会拆开 run：
| 报告断言(假阳性) | 实际文件行(完好) |
|---|---|
| 名字被截断成孤字"夫" | `やる夫`(や・る=假名被丢) |
| JoJo"第五部"梗丢失, 只剩"不知所云" | `…JOJO第5部，不知所云(ry`(JOJO+5被丢) |
| 3406 "三秒内"数字丢失 | `时停　3秒内能逃掉…`(3被丢) |
| 3411 "两天/一只"丢失 | `找了2天才找到1只而已！`(2,1被丢) |
| 3009 "好想睡一觉啊"整句漏译 | `…困　意起来了……。`(困被空格拆成run) |
| 2482/2487 "夫代替/夫的孩子"残缺 | `这可得やる夫代替…`/`怀上やる夫的孩子` |

- 落地修正前必须 `grep 实际行` 复核；报告另列「复核更正」档明示假阳性。
- 「角色名保留日文(やる夫)」≠「名字残缺」——是**术语统一**问题（人工参考用 亚鲁欧）。统一 やる夫→亚鲁欧 时宽度 6=6 等值, 全局替换安全（但 `#` 标题行是否一起改按交付命名决定——本作标题行也改了, 合集目录即显示"时间停止探索者亚鲁欧 第N話"）。

## 确认为真的修正（本会话落地, 供同样错误模式参考）
- **意思反转**：火焰祝福**不适合→最适合**迷宫探索(ch10 帖3527, 因果全反)；这就完了不该被选中的人→**不正是被选中的人吗**(ch4 2860)；完全对やる夫敞开心扉→**完全服从**(ch6 3109)；明天就是现在→为了(更)好明天(ch9 3426, 宽度受限用等宽「为了更好明天」)
- **形近/音近误读**：巨大**玻璃→乌鸦**(ch8×2, ch9×1, カラス/ガラス)；**火力抬太高→近视加深**(ch10 3538)；**福本路人→福本脸**(ch10 3629, 福本伸行脸型梗)；**混合基因→精液混合**；**射精抛弃→注入精液**；稍、稍失礼一下→让开让开都闪开(ch10 3543, 命令语气)
- **字数/量词**：素質あり(残留)→有资格；找了2天/3秒 等实际无错勿改
- **日语残留未中文化**：野盗→强盗、素质あり、塔可→咕哇、雅达巴→糟了
- **术语统一**（等宽优先, 超宽拒写则放弃换写法）：入即出亚鲁欧→入速出亚鲁欧；吉冈特斯/吉甘特斯/单眼巨人→独眼巨人；托尔内克→特鲁尼科；艾莉丝→厄里斯；阿克西斯→阿库西斯；收服/驯服→调教；考试→试炼
- **宽度约束案例**：黄衣人(3字)→"黄色的人"(4字) 在无垫余框线行 +2 宽必超宽 → 本作统一保留"黄衣人", 只把"黄色小人"(4字)→"黄色的人"(4字) 等宽落位。

## 保留/未改（本会话决定, 说明保留理由）
- 神搞错了♪转生来道歉♪（语义可通, 神手误转生致歉, 未定误）
- 砸瓦鲁多/第五部 等玩梗（本地已保留梗或属风格取舍）
- 参考版有而本地无的整句（插进去了/谢谢你 等）：受宽度约束未强补, 列后续
- 画面文字幻觉增补项（如"女忍女忍""史莱姆君又没眼睛"）：未经原图核实, 不动, 待人工

## 校验（落地必做）
- 行数==原文 一一一致; `disp_width` 逐行==SRC **0 错位**（复用 aa_common/aa_translate.disp_width, 勿用旧口径）
- 残留: 只查正文(排除帖头 `^\d+ ：`), 艺术行假名不算
- 重生成交付 html 后浏览器 DOM 抽查: 关键修正串在正文(`试炼`在/`考试`不在), 0 JS 报错
- 修正表进 git（作品 work/ 目录）, 可一键重放/回滚（幂等）
