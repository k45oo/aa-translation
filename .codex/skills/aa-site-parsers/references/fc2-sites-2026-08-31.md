## FC2 R18 年龄门绕过（dl_chapters.py `dl_age_gate`）

1. GET 章节页 → 响应前 5000 字节含 `age_verify` = 撞门。
2. POST `age_verification=1` + `entry_number=<eid>`（**必须匹配该章，错值 404**；URL 正则 `blog-entry-(\d+)` 提取）→ 种 cookie `age_check`/`blog_view`（domain `.mukankei769.blog114.fc2.com` **全站通用**，每进程一次）。
3. **必须用带 cookie jar 的 opener 重取**——直连无 cookie 无限撞门（第一版 11KB 假文件事故：fetch 撞门确认后 continue 重试，但重试走直连 `urlopen` 无 cookie，返回还是年龄门页）。
4. registry 条目加 `dl_age_gate: true`，`dl_chapters.fetch(url, age_gate=True)` 检测撞门自动确认；5 并发共享模块级 CookieJar。

## 本会话其他坑

- **CLI 注册后 enqueue 前必须 `importlib.reload(registry)`**：`_append_registry_entry` 写磁盘后 task_manager 内存是旧快照 → 报「未知作品 <id>」但磁盘已写（重跑显示已存在）。runner 子进程每次启动重新读磁盘不受影响，只有同进程内 enqueue 检查需要新快照。
- **工作台重启后 scheduler 线程可能不自动 tick**（实测任务卡 queued 数分钟）：`@app.on_event("startup")` 线程可能未跑/已崩。诊断：任务文件 mtime 停摆 + API 正常 → 手动 `TM.scheduler_tick()` 一次即启动。
- **任务 finalize 异步窗口**：dl_runner 日志已「DONE」但任务文件 rc=None status=running（心跳 rc=0 但任务文件没同步）→ 手动 `TM._reconcile_task(t)` 后标 done。pid 已退出（exit_code=0）时 reconcile 判 done。
- **temp/add_work_cli.py**（temp/ 下，仓库 gitignore）：CLI 注册 r401 新站作品的复用脚本（parse_url → build_registry_entry → _append_registry_entry → work_meta → reload → enqueue），支持 `--work-id`/`--cn`/`--author`/`--r18`。
