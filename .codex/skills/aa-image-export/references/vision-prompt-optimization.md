# 提示词口径与 6 项优化（2026-08-17 视觉辅助分类实测定稿）

> 背景：AA 图片版嵌字"视觉辅助分类"（vision_classify.py）提示词优化全过程。
> 结论：**视觉分类精度取决于提示词口径，不是模型强弱**——这是 3 新模型补测（gemini-3.7-flash / Qwen3-VL-32B / MiniMax-M3）后最重要的修正。

## ⭐ 两个口径对比（块39 多台词 + 块76 轮廓密集）

| 口径 | gemini-3.7-flash | Qwen3-VL-32B | MiniMax-M3 | glm-4.6v |
|---|---|---|---|---|
| **全图扫描台词行**（给全行文本清单） | 漏 2 条真台词；轮廓行误判台词 | 同左误判 + 误帖头 | **最差**（22-37 全判台词） | — |
| **红框标注 + 只判存疑行**（生产口径） | ✅ 画面 | ✅ 画面 | ✅ 画面 | ✅ 画面（4 模型一致） |

- **全图扫描口径系统性误判**：模型拿全行文本当线索，把 `| : : |` 人物轮廓行当"文字框"→ 误判台词。gemini 文档里"13/13 全对"是单块简单测试的误导。
- **红框口径下 4 模型判定一致** → 生产 vision_classify 用红框口径即可，glm-4.6v 免费已足够，**无需为"更强的模型"升级主力**。
- MiniMax-M3 全图扫描最差（推理模型思考干扰印证）。

## 提示词定稿（vision_classify.py 现行）

```
system: 你是AA字符画分类专家。AA画面=符号/假名拼的图形;台词=可读句子。
- 行内只要有可读中文/日文句子→台词(混合行,即使前面有画面符号)
- 纯符号/假名/纹理(无完整句子)→画面
- 红框行是存疑行,行首红色编号=块内行序号
- 示例: '大嘴巴やる夫→台词'; '| : : | 乂辷ﾝ→画面'(few-shot)
- 严格格式: 行号N: 台词/画面,每行一个
user: 红框行文本(只列红框行,不给相邻行) + 严格格式要求
```

## 6 项优化实测

| # | 优化 | 实测效果 |
|---|---|---|
| ② | **只列红框行**（去掉 ±2 相邻行上下文） | ✅ 有效——相邻行文本让模型"从文本猜判定"而非看像素 |
| ③ | **结构化格式**（`行号N: 台词/画面`）+ 解析容错（T/A/台词行/絵/イラスト 变体） | ✅ 有效——解析率从"解析率低"→ 一次 4/4 全判定（8540 块17：三模型全失败 → glm 5.6s 4/4） |
| ⑤ | **few-shot 示例**（`大嘴巴やる夫→台词`、`乂辷ﾝ→画面`） | ✅ 有效——帮模型理解 AA 语法 |
| ⑥ | **混合行指令**（"行内有可读句子→台词，即使前面有画面符号"） | ✅ 有效——正确处理 `! / ヽu \| 被同年级...` 类混合行 |
| ① | ~~整行浅红高亮底色~~ | ❌ **负优化已回退**——高亮底色让模型把整行高亮区当"文字框"，把轮廓行误判台词（行28 判 text 而纯红框判 art） |
| ④ | ~~v2 先验~~（`[规则:text/lz_dotted]` 附给模型） | ❌ **负优化已回退**——模型盲从规则先验，把轮廓行误判台词（即使视觉上是画面） |

## 效果与教训

- **优化后失败块 65→9 个（-86%）**，v3 总判定 3339→3412 行。
- 教训：**提示词的"新增信息"未必是增益——高亮/先验这类"帮助"会引入模型盲从**。改提示词必须**单块实测对照**（同一块、同口径、只变一个变量），负优化立即回退。
- 关联：嵌字规则修复（2026-08-17 同批）——ART_SYMS 补半角 `!/ヽノ`（行首半角画面符号不再整行误嵌）+ 独立片假名词检测（`レジェンゴ` 外来语补嵌）+ 台词段扩展并入括号（`男子最强（笑）`）。验证要点：`no_dialogue` 画面行 0 误嵌。
