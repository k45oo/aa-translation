# 嵌字重绘 (M16) + 视觉辅助分类 (2026-08-14~16)

楼主楼(帖头含◆,整楼冻结不加大)的台词——text 行 + mixed 行台词段——用 **SimHei fs+2 嵌字重绘**:
清背景矩形(外扩2px) → 逐字符 pick 绘制(SimHei 缺字回退 PGothic)。艺术段像素不动。
嵌字必须在 PNG-8 quantize 之前执行(特殊色锚点方案会被量化杀死)。

## v2_text_spans 识别逻辑(scripts/tools/aa_to_images.py)
主源1: v2 segments 中 kind=text 且 conf≥0.5 或 conf 缺失(0032 '彼此' 段 conf=None 是真台词)
主源2: v2 整行 kind=text(纯文本行,无 segments)→ 整行嵌字
兜底1: reason 含 lt(文本过短,如 '３．奈良/草/人名' 误判 art)+ 汉化后含语义中文 → 中文段定位嵌字
兜底2: reason 含 lt/dotted + 中文段 → 向前后扩到空白/艺术符号
**no_dialogue 画面行绝不兜底**(从劜/八芹坏/爻乂爻 全是 no_dialogue——纹理字表 _ART_TEXTS
枚举不完是死路,从 v2 reason 入手才是正解)

## 视觉辅助分类(2026-08-16,用户 grilling 定稿)
**背景**: 纯规则分类(line_classify_v2.py)核心缺陷 = ART_KANJI 手工枚举不完(劜/芹/坏/斗匕/圦
漏网)→ 误嵌与漏嵌同源。**AA 行强上下行关联**(角色=连续10-20行轮廓跨行延续),单行判定永远有
歧义 → **必须按块(楼)区分**,视觉模型必须参与。

**管线**: 规则粗筛存疑行 → 渲染块图红框+编号标注 → 视觉模型看块图+行文本 → 行号→台词/画面
→ line_meta_v3/*.json 落盘 → 嵌字消费(v3=art 停嵌 / v3=text 补嵌)

存疑行启发式(第1话 361 行):
- 误嵌嫌疑: v2_text_spans 非空 且 art 占比>35%(画面被当台词)
- 漏嵌嫌疑: spans 空 且 含连续中文 且 art<25%(台词没嵌)
- 帖头行跳过(不嵌字,不该送视觉)

**视觉模型优先级**(用户确认): glm-4.6v(免费 6000万token, 2-50s/块, 主力) →
Qwen3-VL-8B(质量最好已实测0误判, 但 **不免费**: 输入¥0.5/M 输出¥2/M) → mimo-v2.5(慢30-60s, 兜底)

**Qwen3-VL 400 修复**: 批量 400 根因 = 图片超 1024px(原尺寸标注图) + 上下文过长 →
缩放图片最长边≤1024 + 只传"红框行±2行"文本。

**验证**: entry_8532 全章 19 存疑块/27 行(9 art + 18 text);v3 校正精准命中规则唯一判错行
(3107 画面'汽'字被视觉判 art → 停嵌,块0086 差异 442px)。

**断点续跑**: 已有 v3 文件且>10字节的章节自动跳过。

## AAhub 素材统计(aahub_stats.py)
15023 个 .mlt(Shift-JIS 编码,[SPLIT] 分帧,2.4GB)全量解析 → 137万帧/84万艺术行/3384去重汉字。
**产出**: 542 个艺术用字候选(艺术行≥100次),覆盖手工 ART_KANJI(77字)漏网的 匕圦芹艾斗心。
**关键教训**: 候选里混入大量语义常用字(魔/龍/世界/俺)——AA 素材里角色台词帧也被统计,或角色
身体确实用这些字拼。**纯字符频率无法区分"魔字作画"与"魔字作词",不能直接替换 ART_KANJI**,
须视觉模型对含候选字的存疑行裁决。AAhub 价值 = 候选集(缩小视觉排查范围),不是最终分类器。

**Windows 坑**:
- ProcessPoolExecutor 不能 pickle 嵌套函数 → worker 必须模块级(_process_file)
- 后台长任务用 `> log 2>&1` 而非 `| tail`(管道缓冲会静默卡死: 20分钟 CPU 仅0.06s);
  用 powershell Get-Process CPU 时间判断是否真卡死
- 视觉批量要 sleep(0.5) 限流缓冲;glm 偶发"解析率低"→ 换下一模型,解析容错
  (容忍 'N: 画面(AA)' 括号/多余后缀/大小写)
