# 嵌字第七轮修复（2026-08-17 用户 2 项反馈：片假名外来语漏嵌 + 行首半角画面符号误放大）

> 承接 embedding-round6.md。第七轮用户手机实测反馈 2 类问题，根因是**台词段识别边界漏了
> 半角画面符号 + 片假名外来语**，ad-hoc 验证 5 项 ALL PASS。

## 用户反馈 → 根因 → 修复

1. **39 图行1239 `大嘴巴やる夫　男子最强（笑）　レジェンゴ　等被网友命名了` 中间漏译没放大**
   - 根因两层：
     - `（笑）` 的括号在 ART_SYMS → 台词段正则 `[^\s+artset]{2,}` 把"（笑）"当艺术段切掉
     - `レジェンゴ`（片假名外来语）在 ART_KATA → 纯片假名段被当艺术字跳过（不嵌字）
   - 修复：
     - **台词段向两侧扩展**：中文段找到后，`while` 扩到非空格/非画面符号/非画面假名
       （`_art_punct` 只含框线类，**不含括号**——括号是台词成分）
     - **独立片假名词检测**：`re.finditer(r'[\u30a0-\u30ff]{2,}', txt)` 连续≥2 片假名
       且不含画面假名（`_is_art_kana` 排除 `ヽノー=―ゝ丶`）→ 台词段（外来语）
     - 去重条件用**重叠**（`s0 <= m.start() < s1`）而非相邻——紧邻但被空格隔开的
       不同台词段（"男子最强（笑）" vs "レジェンゴ"）都要嵌

2. **76 图行2671 `! 　 /　　　ヽ　u　　　|　　　被同年级的女生讨厌了` 行首 AA 误放大**
   - 根因：art 占比 9% ≤15% 阈值 → 走整行嵌字；且行首第一个非空字符是 `!`（半角感叹号，
     **不在 ART_SYMS**——之前只补了全角）→ 行首画面判断失效 → 整行嵌把 `! / ヽ u |` 放大
   - 修复：**ART_SYMS 补半角画面符号 `!/ヽノ`**（`/` 半角斜线、`ヽノ` 画面假名，
     都是 AA 行首常用画面字符）→ 行首非空字符判 art → 走台词子串嵌 → 只嵌"被同年级…"

## 核心教训

- **ART_SYMS 必须覆盖半角画面符号**：`! / ヽ ノ` 等半角/假名装饰是 AA 行首常客，
  漏了它们 → 行首画面判断失效 → 整行误嵌。补全角时同步想半角。
- **片假名 ≠ 画面**：`レジェンゴ` 是外来语台词，`ヽノー=―` 才是画面假名。
  判定要区分——连续≥2 片假名 + 非画面假名 = 外来语台词段。
- **台词段扩展允许括号**：`（笑）` 是台词成分，扩展边界（`_art_punct`）不能含括号
  （round6 把 `{}（）()` 加进 ART_SYMS 是防整行嵌；但**子串扩展的边界集是另一回事**，
  不能直接复用 ART_SYMS——否则括号台词会被切断）。
- **spans 去重用重叠非相邻**：紧邻但空格隔开的不同台词段都要嵌，相邻判断会误去重。
