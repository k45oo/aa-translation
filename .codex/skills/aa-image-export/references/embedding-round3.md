> 承接 embedding-plan.md（第一/二轮）。第三轮用户手机实测反馈 4 类问题，
> grilling 定位根因后全部修复，ad-hoc 验证 14 项 ALL PASS。

## 用户反馈 → 根因 → 修复（每条都是坑）

1. **"很多楼主图 AA 行被误放大"（最严重，0001/0011/0019 等）**
   → 兜底2（中文定位台词段）无视 v2 reason，对 `no_dialogue` 画面行也生效——
   `从劜`/`八芹坏`/`爻乂爻`/`斗匕`/`圦`/`仡心` 全是 AA 轮廓汉字被当台词。
   ⚠️ **纹理字表枚举是死路**（劜/芹/坏/艾/斗匕/圦/仡心… 永远补不完）。
   证据：全章 19 个兜底2 触发行**全部 reason=no_dialogue**（v2 已明确判"无对话"），
   真台词（奈良/阿知贺/红豆串）reason 是 `lz_text_lt5`/`lz_mixed`/`lz_dotted`。
   修复：**兜底2 仅对 reason 含 `lt` 或 `dotted` 的行生效，`no_dialogue` 一律跳过**——
   从 v2 判定源头解决，误嵌清零。

2. **文字重叠（0026"种人"、0001"【红豆】小ー咲ー【咲 -saki-】"）**
   → 多个 spans 段各自清背景+重绘，段间 SimHei 字宽膨胀（fs+2）导致相邻文字重叠。
   修复：**嵌字前合并相邻 spans**（间距≤1 字符宽合并为一段，一段一清一绘）。
   0032 实测 `(48,52)+(52,73)` → `(48,73)` 一段。

3. **0011 依旧右偏** → 第二轮逐字符定位已修，第三轮确认 v8/m16 ink x 完全一致（198..510）——
   前导空格跳过保持原文位置即可（已含在逐字符逻辑）。

4. **0032 "彼此 为了…"只放大"彼此"，后面没放大**
   → v2 segments 把真台词段标 **kind='text' 但 conf=None**（`[48:52] '彼此'`、`[52:73] '为了…'`），
   而 conf 过滤 `(s.get('confidence') or 0) >= 0.5` 把 None 当 0 跳过。
   ⚠️ **v2 对 kind=text 无置信的段不设 conf 键**（不是 None 值，是键缺失）。
   修复：**kind='text' 时 conf 缺失也按"段含中文"判定**
   （`if conf is not None and conf < 0.5: continue`——只有显式低置信才跳过）。

## v2_text_spans 最终判定逻辑（第三轮收敛版，覆盖第一/二/三轮全部修复）

```
1. v2 有 segments → 每段：kind=='text' 且（conf 缺失 或 conf≥0.5）且段内含中文 → 嵌；
   一个有效段都没有 → 落兜底2（segments 分支不再无条件 return）
2. v2 整行 kind=text → art 占比>25% 则只嵌非艺术连续段（含 ヽ_ノー=― 补充字符）；否则整行嵌字
3. v2 kind=art/mixed → reason 含 'lt' 且汉化含语义中文 → 整行嵌字（兜底1）
4. mixed 且以上都没命中 → 兜底2 仅当 reason 含 'lt'/'dotted'：中文段向前后扩边界嵌字
   （no_dialogue 绝不兜底——第三轮核心修复）
5. render_block 收集 embed_jobs 前先合并相邻 spans（间距≤1 字符）
```

## 第三轮验证（ad-hoc ALL PASS，14 项）

- 画面行 5 例（从劜/八芹坏/爻乂爻/乂爪/乂少）0 段；真台词 4 例（奈良/阿知贺/可惜/为什么）正确嵌字
- 0032 合并为一段 `彼此 为了…一起加油吧！`；0011 不右偏 x=(198,510) 与 v8 逐像素一致
- 嵌字生效 43/90 块；纯文本 612、PNG-8 关键色 0 缺失（零回归）

## 核心教训

- **v2 的 reason 字段是最可靠的"有无对话"信号**：`no_dialogue`=纯画面（绝不嵌）、
  `lt`/`dotted`=有文本但分类保守（才走中文验证）。比中文正则/纹理字表可靠一个数量级。
- **v2 segments 的 conf 语义混乱**：真台词段可能 kind='text' 但 conf 键缺失、或 kind=None conf=None、
  或 kind=None conf=0.55——不要信任任何单一字段，一律"段含中文才嵌"兜底。
