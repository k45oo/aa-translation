## 用户反馈 → 根因 → 修复（每条都是坑）

1. **"【咲　 -saki-】"中 咲 和 -saki- 重叠**（0001 等多处）
   → v2 把台词 `【红豆】小ー咲ー【咲　-saki-】` 切成 3 段：`【红豆...咲　`(69:80) + `saki`(82:86) + `】`(87:88)，
   中间夹 art 段 ` -`(80:82)。`saki`/`】` 段**无中文** → 被"段含中文才嵌"过滤跳过 → 只嵌前段，
   后段保持原字号 → 重叠。
   修复（两层）：
   - `v2_text_spans` segments 分支：**无中文段仅当紧邻已选中文段（间隔≤2 字符，容 ` -` art 段）时纳入**
     （尾缀并入：`saki` 距中文段 2、`】` 距 `saki` 1，链式并入）
   - render_block 扩展段尾：`while s1<len(txt) and (txt[s1].isalnum() or txt[s1] in '-ー』」]】』)）'): s1+=1`
   ⚠️ **台词尾缀（-saki-、』』、】】）常被 v2 切成独立无中文段**——必须"含中文段 + 邻近尾缀并入"两阶段收集。

2. **"发誓在这个阿知贺重新站起来！"整行放大错位、最右看不到**（84 图"作为贤者亚鲁欧"同）
   → v2 kind=text（lz_dotted）行 art=21%，**低于第三轮 25% 阈值漏网** → 整行嵌字把画面字符
   （`｛ ゝ ヽ ／ヽ` / `| .i ||lliilil ll|`）也放大 → 错位。
   修复（三连）：
   - art 阈值 25%→**15%**
   - **行首非空字符是艺术字符**（`first_ns in ART_SYMS or ART_KATA or 'ヽ_ノ'`）也走子串嵌字——
     画面在前台词在后是典型布局，占比可能不高但行首特征强
   - **子串须含中文**（`if not _HAN2_RE.search(m.group(0)): continue`）——`lliilil`/`.i` 画面字母纹理
     无中文被过滤
   ⚠️ 阈值永远有漏网案例（21%<25%），**行首艺术字符 + 子串含中文**两个特征判定比纯阈值可靠。

3. **"个"字丢失**（3020 行 joined='发誓在这' + '阿知贺重新站起来'）
   → v2 段边界切在台词中间：`发誓在这|个|阿知贺`，"个"(39:40) 在段外被跳过。
   修复：render_block 合并 spans 后**补缺口**——span 间若夹着中文（`_HAN2_RE.search(gap)`）则并入前段
   （台词内部不应有中文缺口）。
   ⚠️ **v2 segments 边界可能在台词中间切分丢字**——合并后必须检查缺口，中文缺口一律并入。

4. **72 图"现在在做什么？】"后半"么？】"看不到**
   → 行 2515 两段 `(56,75)+(75,83)`（`【印象中...亚鲁欧　　　　　` + `现在在做什么？】`），
   合并逻辑已把两段并为一段，嵌字范围覆盖完整。
   修复：无代码改动（第三轮合并已生效），验证确认 spans 为完整一段含 `么？】`。

## v2_text_spans segments 分支最终逻辑（第四轮收敛版）

```
有 segments:
  1. 收集所有 kind=='text' 段（conf 缺失或 ≥0.5）→ 标记每段是否含中文
  2. 含中文段必选入 spans
  3. 无中文段若与前/后已选中文段间隔 ≤2 字符 → 也纳入（台词尾缀并入）
  4. 一个有效段都没有 → 落兜底2（reason lt/dotted 才走，no_dialogue 绝不）
整行 kind=text:
  art 占比>15% 或 行首非空字符是艺术字符 → 只嵌含中文的子串（正则段+中文过滤）
  否则整行嵌字
render_block 收集 embed_jobs：
  a. 段尾扩展（字母/数字/-/闭合标点）
  b. 合并相邻 spans（间隔≤1）
  c. 补中文缺口（span 间夹中文并入前段）
  d. 逐字符 pick() 绘制（SimHei 缺字回退 PGothic）+ 空格跳过保持原文 x
```

## 核心教训

- **v2 segments 边界不可信**：可能切在台词中间（丢字）、把尾缀切成独立无中文段（重叠）、
  段边界夹 art 段（` -`）。**收集后必须做三件事：尾缀并入 → 相邻合并 → 中文缺口补齐**。
- **阈值判定永远有漏网案例**（21%<25%）——用"行首艺术字符 + 子串含中文"结构特征补。
- 用户报"某字消失/重叠"时先看 spans 的**段边界完整性**（缺口/尾缀），别急着调阈值。
