# 汉化版(中文台词)章节级 R18 判定

适用:网上已汉化 AA 资源目录(交付HTML/<作品>/ 每章一简体 html),**源码是中文台词**,不能用面向 aa 原文的日文 STRONG/NORMAL 词表(chapter_prep.py 那套)。

## 工具
- `scripts/tools/r18_judge_ch.py` → 生成 `<dir>/r18_verdict.json`(每章 `{r18:yes|no, words:[命中词]}`)
- 生成器 `gen_standalone_reader.py` 自动发现该文件,给 yes 章 nav 标签加红 R 角标(`<sup class="r18-badge">R</sup>`,CSS `.r18-badge{color:#ff4d4d;font-size:10px;vertical-align:super;...}`)

## 判定规则
- **强词命中 1 个即判 R18**:做爱/性交/口交/内射/精液/射精/高潮/阴道/阴茎/插入/奶子/乳头/发情/中出/受精/怀孕/交合/交配/淫乱/淫荡/色情/生殖器/下体/私处/快感/爱液/淫水/肉棒/小穴/龟头/大屌/巨乳/自慰/勃起 等
- **软词(裸体/全裸/工口/色色...)需 ≥3 个不同词**才判
- **排除系统/误导词**:`调教` 不算——008 话「【调教成功】史莱姆」是游戏系统提示,非色情;类似地 `H` `身体` `工口`(单独)不作为强词

## 校准基准(用户给定,2026-08-22)
| 章 | 判定 | 期望 |
|---|---|---|
| 001 / 062(上/下) | yes | 有 R18 |
| 008 / 012 / 013 | no | 无 R18 |

判定脚本落地前**必须**用此校准集先验:六项全过才算及格。R18 向作品整体 yes 比例会高(本作 301 章标 R=184,~61%)。

## 关键坑
- **r18_verdict.json 键是完整文件名(含 .html)**;生成器 `e['base']` 是去 .html 的 → 载入须归一 `k[:-5] if k.endswith('.html') else k`,否则 0 角标**静默**进合集(浏览器 DOM 里 `.r18-badge` 计数=0 但 CSS rule 在,查 API 只看到这现象要想到 key 失配)。
- **浏览器验证**:看 `.nav-item .r18-badge` DOM 计数 + 校准章 label 的 on/off,别信视觉模型。
