# 角色别名字段方案（2026-08-27 grilling 定稿，待实施）

用户问题：`泄矢诹访子` 和 `青蛙子`（ケロちゃん）是**同一个角色**（后者是昵称），但译文里两者**同时存在**（原文不同地方用不同称呼，各自按原文翻译，不能强行合并成单一译名）。真正的诉求在**素材统计**和**人物简介**层面把同一角色的多个译名归并。讨论是否给术语表扩充"昵称/外号/短名"字段。

## 关键架构事实（决定方案形态）

**翻译注入 `_filter_glossary_pairs` 只读 `glossary` 替换对（57 对），完全不读 `角色` 表**（902 条）。`角色` 表只被两处消费：
1. `KNOWN_NAMES` / known_names 白名单（漏译检测容错）
2. 工作台 `_material_match_names` / `material_display_parts`（素材名→匹配词展开 + 显示名解析）

推论：**昵称关联若加在角色表 `_same_as`/`别名` 字段，翻译注入层看不到**——所以"同一角色多译名统一"不能走翻译注入（也符合用户要求：译文两者都保留），只能落在 **素材统计 + 人物简介**。

三层角色数据（各自独立，翻译注入各自生效）：
| 层 | 保存位置 | 例子 | 消费方 |
|---|---|---|---|
| 全局替换对 | glossary.json `glossary` | `結月ゆかり→结月缘` | 翻译注入（全部作品） |
| 全局角色表 | glossary.json `角色` | 902 条（青蛙子独立条） | known_names 白名单 + 工作台显示 |
| 作品知识库 | work/*_knowledge.json `人物` | `ゆかり→结月缘`、`ケロちゃん→泄矢诹访子(青蛙子)` | 本作翻译注入（memory_hint） |

## 方案 B 定稿（5 个 grilling 决策）

1. **昵称/同名角色关联层级**：不在翻译注入层（译文保留两者），在 **素材统计 + 人物简介**归并角色身份。
2. **实现方式**：角色表加 `别名`（数组）字段；`_material_match_names` 读它展开匹配词。materials 只填规范名（`泄矢诹访子`）即可统计到 `青蛙子`/`ケロちゃん`/`洩矢諏訪子` 全部出现；人物简介归并；翻译译文两者保留。
3. **变体独立条目去留**：保留（902 条不动），规范名条目加 `别名`；变体条目可搜但不参与独立计数。
4. **别名字段粒度**：只放明确指代该角色的昵称/别称（青蛙子/ケロちゃん），**不放单字/常用词短名**（`雷` 会误伤"雷电"，靠 `_material_match_names` 已有 `len>=2` 过滤兜底但语义上仍危险）；短名（ゆかり）走作品层知识库。
5. **实施范围**：本次只补 sujin_saigo 明确关联（`泄矢诹访子.别名=["青蛙子","ケロちゃん"]`）+ 落地 `_material_match_names` 读 `别名` 字段；**不强扫全表**（902 条找同角色成本高易误判），随作品增量补——延续"遇到作品的知识库增量"模式。

## 别名_of：候选层的别名归并标记（2026-08-28 grilling 追加，待别名实施时一并落地）

**问题**：若别名字段落地，`glossary_candidates.json` 的 AI 提取会把 `青蛙子(ケロちゃん)` 标成独立"角色"，
promote 时建独立人物——与"青蛙子应作泄矢诹访子别名归并"冲突。故需在**提取层**先支持别名归并。

### grilling 决策（4 项）

1. **候选形态**：type 保持 `角色`，加**可选字段 `别名_of`**（人工确认时填目标角色，如 `青蛙子.别名_of=泄矢诹访子`）。
   **AI 不猜跨角色归并**（跨批识别同角色不可靠），归并是人工判断——契合"别名只放明确昵称"既有决策。
2. **promote 目标层**：`别名_of` 非空 → 进**全局角色表**目标条目的 `别名` 数组（青蛙子不建独立作品层人物，
   避免拆分）；`别名_of` 空 → 建作品层独立人物（现状）。素材统计经 `_material_match_names` 展开全部变体。
3. **目标不存在**：目标角色已在全局角色表 → 加别名；不在 → 提示"先 promote 主角色"，不自动造主条目
   （避免别名指向空，保持 promote 确定性）。
4. **实现时机**：随别名字段实施一并落地（当日写入 promote 分流 + 全局角色表别名）。本次仅记录。

### promote 分流规则（别名_of 加入后）

| 候选 type | 别名_of | promote 动作 |
|---|---|---|
| 角色 | 有 | 目标在全局角色表？→ 其 `别名` 数组加当前 term；不在 → 提示先promote主角色 |
| 角色 | 无 | 建作品层独立人物（现状） |
| 专名/术语/拟声 | - | 术语块（现状，`别名_of` 忽略） |
