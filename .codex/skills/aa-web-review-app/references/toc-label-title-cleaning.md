# 目录标题清洗规则 toc_label（2026-08-20 用户 3 条纠正后定案）

## 用户口径（逐字）
1. 「（汉化）这两个字不需要」——白头汉化标题自带「（汉化）」尾巴
2. 「時間停止探索者やる夫」「トレセン学園　人狼部」这两个属于**作品名不是副标题**
3. 「章节名不用显示作品名（短篇集除外）」

## 实现（aa_web_app/main.py#toc_label）
```python
def toc_label(lab, work_title):
    s = lab.strip()
    for suf in ("（汉化）", "(汉化)"):
        if s.endswith(suf):
            s = s[:-len(suf)].rstrip()
    if work_title:
        m = re.search(r"第\s*\d+\s*[话話回]", s)
        if m:
            prefix = s[:m.start()]
            if work_title in prefix:
                s = s[m.start():]
    return s or lab
```

## 规则
1. **去「（汉化）」「(汉化)」**尾巴（只去结尾，不影响标题正文）
2. **剥离作品名前缀**：找「第N话/話/回」首次出现，若其**前缀包含 cfg.title**（jikan「時間停止探索者やる夫　第1話」、saki「【あんこ】さーきー【咲 -saki-】　第2話」）→ 从话数处截断
   - **副标题保留**：「時間停止探索者やる夫　第205話「負けて死ね ④」」→「第205話「負けて死ね ④」」
3. **短篇集例外**：标题无话数（yaruohiroba「【２０２６年　夏の短編祭】…【 Iコース 】」）→ 保留完整；前缀不含作品名（白头「回归篇 第一话…」、touhou「第2話…」）→ 保留完整

## 关键点
- **只改展示不改数据**：toc label 清洗，txt/正文渲染不动
- 正则必须同时匹配 `话|話|回`（日文标题用「話」「回」）
- title 悬停（title 属性）保留完整原文标题（含作品名），可见文本才清洗
- 汉化标题优先：`tcache.get(raw) or raw`（title_translations.json 缓存键=完整日文标题）→ 再 toc_label
- 验证：curl 阅读页 grep `>[0-9]*\. [^<]*` 看目录可见文本
