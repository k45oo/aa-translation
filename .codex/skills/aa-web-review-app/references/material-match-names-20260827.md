# 素材统计防误判 + 仅日文支持（2026-08-27）

## 背景问题（r401_metsubou 实测）
1. **「L（死亡笔记）」误判 2851 次**——汉化文本行号前缀是 `L<数字>`（`L5 [主]`、`L64`），单字符名 count 时全命中行号标记。
2. **爱丽丝（多娜多娜）匹配不到**——术语表无"多娜多娜"作品条目；文本有 3 种写法（愛麗絲 39 / 爱丽丝 137 / アリス 13）。
3. **泉奈（碧蓝档案）匹配不到**——术语表全名「久田泉奈/久田イズナ」，文本用短名「泉奈」「イズナ」。

## 核心改动（aa_web_app/logic.py）
- **`_material_match_names(name)`**（新增）：素材名 → 匹配词集合（列表）。
  - 先剥离「仅日文」后缀**再** `_split_mat`（顺序坑：括号不在末尾时 `（作品）` 拆不出）
  - 基础名(用户输入)本身作匹配词（支持短名）；查角色表「作品精确 + 基础名部分匹配」（久田泉奈 含 泉奈）
  - **作品不符时仍收集日文短名**（`_jp_short_name`：`re.search(r"[ァ-ヶ]+$", jp)` 去姓，天童アリス→アリス、久田イズナ→イズナ）——多娜多娜爱丽丝靠天童アリス 的短名补上アリス
  - **繁简变体**（`_add_trad_variants`，zhconv 双向：愛麗絲↔爱丽丝）
  - 「仅日文」→ 只留含假名词（`_has_jp_chars`）
  - **排除 len<2 单字符**（L 等行号碰撞）
- `material_frequency` / mat-scan（main.py 955-968）改用匹配词集合：`words = [w for w in {cn,jp} if w and len(w)>=2]` + `sum(t.count(w))`。
- `_material_names_for`（返回 (cn,jp) 二元组）**保持原样**——test_aaweb.py 锁定了它的契约，新逻辑走 `_material_match_names`。
